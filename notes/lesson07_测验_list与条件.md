- A. `lst.add(5)`

- C. `lst.push(5)`

## 二、判断题（对 / 错）

**1.** `list` 可以存不同类型的元素，例如 `[1, "李宏", True]`。对

**2.** `nums[-1]` 表示列表最后一个元素。对

**3.** 条件语句里写 `if score = 60:` 和 `if score == 60:` 一样。我觉得一样，但是可能一个意思是值是否是60，一个是判断？存疑--应该是错误

**4.** Python 用**缩进**表示代码块，不像 C 用 `{}`。对

**5.** 空 tuple 可以写成 `()`。对

**6.** `if` 下面只有一行代码时，可以不写缩进。对--必须写缩进

**7.** `[90, 85, 88]` 三个分数求平均，可以写 `sum(scores) / len(scores)`。对

**8.** tuple 比 list 快，所以所有数据都应该用 tuple 存。错
