## 〇、先过一遍（做题前看）

### 日常只用 `main`

这个学习仓库约定：**天天在 `main` 上改 → Commit → Push**。  
另一台：**先 Pull**，再继续学。

现在不要自己建一堆分支练手——课找不到、两台对不上，比「学会分支」更亏。  
（以后实习/正式项目再学分支。）

### Commit vs Push（必须分清）

| 动作 | 人话 | 在哪 |
|------|------|------|
| **Commit** | 给本机拍一张「存档点」 | 只在你这台电脑 |
| **Push** | 把存档点上传到 GitHub | 云端；另一台才能 Pull 到 |
| **Pull** | 从 GitHub 拉别人/另一台推上去的存档 | 换电脑、隔几天先做 |

只 Commit 不 Push → 另一台 / 网页上看不到今天的进度。

### `.gitignore` 是干什么的

告诉 Git：**这些文件不要进仓库**。

本仓库至少应挡住：

- `.venv/` / `venv/`（虚拟环境很大、每台自己建）
- `__pycache__/`、`*.pyc`
- `.env`、密钥
- `dca-ledger/data/private/`（真实账单）

样例 `data/ledger.csv` **可以**提交；真实账单不行。

### 提交前看一眼 Changes（GitHub Desktop）

| 可以交 | 不要交 | 先问再交 |
|--------|--------|----------|
| `exercises/`、`notes/`、`algo/`、`dca-ledger/` 当天作业 | `.venv`、`__pycache__`、真实账单、密钥 | 突然多出来的大文件夹、无关截图 |

**不要**习惯性「全部 Add」；有陌生文件先问。
