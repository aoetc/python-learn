## 选择

1. 方法重载要求（   B ）  
   A. 方法名必须不同  
   B. 方法名相同，参数列表不同  
   C. 方法名相同，只有返回类型不同即可  
   D. 必须写在不同的类里  

2. 下列哪组可以构成重载？（ B ）  
   A. `void f(int a)` 与 `int f(int a)`  
   B. `void f(int a)` 与 `void f(int a, int b)`  
   C. `void f(int a)` 与 `void f(int x)`（仅参数名不同）  
   D. 以上都能  

3. 构造方法可以重载吗？（ B ）  
   A. 不可以  
   B. 可以，靠参数列表区分  
   C. 只能重载一次  
   D. 只有 main 可以重载  

4. 重载（overload）和覆盖（override）的粗分：（  B）  
   A. 完全是一回事  
   B. 重载：同类同名不同参；覆盖：子类改写父类同签名方法（后面会细讲）  
   C. 重载只能用于构造，覆盖只能用于普通方法  
   D. Java 没有覆盖

## 判断

5. 参数个数相同、类型顺序也相同，只改参数名字，可以算重载。（ 错 ）对 / 错  

6. `add(1, 2)` 会优先匹配 `add(int,int)` 而不是 `add(double,double)`。（ 对 ）对 / 错  

7. 一个类里可以有多个构造方法。（ 对 ）对 / 错  

8. 重载是运行时由 JVM 临时改方法名实现的。（ 错 ）对 / 错
