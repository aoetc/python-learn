## 一、今天的题（二选一）

### 推荐新题：242 有效的字母异位词

| 项 | 内容 |
|----|------|
| 题号 | **242** |
| 中文名 | 有效的字母异位词 |
| 链接 | https://leetcode.cn/problems/valid-anagram/ |
| 建议文件 | `algo/242_valid_anagram.py` |
| 用到什么 | **dict**（或计数）：两个字符串字母种类和个数是否一样 |

**题意（人话）：**  
给两个字符串 `s`、`t`。若 `t` 只是把 `s` 的字母重新排了一下（字母出现次数完全一样），返回 `True`；否则 `False`。

例子：

- `s = "anagram"`, `t = "nagaram"` → `True`  
- `s = "rat"`, `t = "car"` → `False`

最小思路（自己敲，别整段抄）：

```text
如果长度不同 → False
用 dict 统计 s 里每个字母出现几次
再扫 t：每个字母次数减一（或另建一个 dict 再比较）
最后看是否对得上
```
