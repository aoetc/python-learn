## 〇、先过一遍（约 10 分钟，口语版）

### 容器四件套

| 造的时候 | 是什么 |
|----------|--------|
| `[]` | list，可改、可重复 |
| `()` | tuple，一般当「一组固定值」 |
| `{键: 值}` | dict |
| `{值, 值}` | set，自动去重 |
| `{}` | **空 dict**（不是空 set） |
| `set()` | 空 set |

变量后面的 `[]`：`scores[0]`、`grade["李宏"]` → **取值**，不是在造 list。

### 判断与循环

- `=` 赋值，`==` 比相等；`if` 里用 `==`
- `if` / `for` 下面必须缩进
- 遍历 list：`for x in items:`

### 函数

- `def` 打包；`return` 交结果（题目说返回就别只 `print`）
- 默认参数可省略：`def f(a, b=0)`
- `*args` → 多出来的位置参数收成 **tuple**；`calc(*nums)` 是拆开再传
- `**kw` → 多出来的 `名=值` 收成 **dict**；没有时是 `{}`
- `def f(a, *, city)`：`*` 挡板，后面必须 `city="杭"`

### 模块（直觉）

- 模块 = 可 `import` 的 `.py`
- `if __name__ == "__main__":`：只有直接运行才跑测试

### 错误处理

- `input()` 得到 **str**
- `int("60")` → 整数 60；`int("abc")` → `ValueError`
- `try/except`：接住错误，别闪退

### 有效括号（一句）

篮子装左括号；来右括号就配 **最上面** 那个（后开先关）。

## 一、选择题（单选）

**1.** `names = {"李宏", "李宏", "王五"}`，`len(names)` 是？B

- A. 3  
- B. 2  
- C. 1  
- D. 报错  

**2.** 空的 `{}` 是？B

- A. 空 set  
- B. 空 dict  
- C. 空 list  
- D. 空 tuple  

**3.** `grade = {"李宏": 90}`，取分数应写？B

- A. `grade(李宏)`  
- B. `grade["李宏"]`  
- C. `grade.李宏`  
- D. `grade[0]`（一定是 90）  

**4.** `if score = 60:` 这种写法？B

- A. 正确，判断是否等于 60  
- B. 错误，判断相等要用 `==`  
- C. 正确，和 `==` 完全一样  
- D. 只有在函数里才能这样写  

**5.** `def greet(name, title="同学"):`，`greet("李宏")` 时 `title`？B

- A. 报错  
- B. `"同学"`  
- C. `None`  
- D. `"李宏"`  

**6.** `def f(a, *, city):` 正确调用？B

- A. `f(1, "杭州")`  
- B. `f(1, city="杭州")`  
- C. `f(city="杭州")`  
- D. `f(1)`  

**7.** `def person(name, **kw):`，`person("李宏")` 时 `kw`？C

- A. `None`  
- B. `[]`  
- C. `{}`  
- D. 报错  

**8.** `nums = [10, 20]`，`def calc(*numbers):`，推荐？B,这里应该不是推荐的问题吧，应该只有b可以用吧

- A. `calc(nums)`  
- B. `calc(*nums)`  
- C. `calc(**nums)`  
- D. `calc(nums[])`  

**9.** 用户输入 `60`，`int(input())` 的结果通常是？B

- A. 报错（字符不能转）  
- B. 整数 `60`  
- C. 字符串 `"60"`  
- D. `True`  

**10.** `int("abc")` 通常触发？A

- A. `ValueError`  
- B. `NameError`  
- C. 得到 0  
- D. 得到 `None`  

**11.** `([)]` 作为括号串是否有效？A--B

- A. 有效，种类都有配对  
- B. 无效，必须后开先关，最里面的要先关上  
- C. 有效，因为有 `(` 和 `)`  
- D. 只能用栈以外的方法判断  

**12.** `if __name__ == "__main__":` 的主要作用？B

- A. 让程序跑更快  
- B. 只有直接运行该文件时才执行下面代码；被 import 时通常不跑  
- C. 定义模块名字  
- D. 必须写在每个函数里面
