## 选择

1. `class B extends A` 表示（  ）  
   A. A 是 B 的子类  
   B. B 是 A 的子类，继承 A  
   C. A 和 B 毫无关系  
   D. 必须写在不同文件  

2. 子类构造中调用父类构造，应使用（  ）  
   A. `this(...)`  
   B. `super(...)`  
   C. `parent(...)`  
   D. `new A(...)`  

3. 关于覆盖（override），正确的是（  ）  
   A. 和重载完全一样  
   B. 子类写一个与父类**同名同参数**的方法，替换父类行为  
   C. 只能改返回类型、参数必须不同  
   D. 只有构造方法能覆盖  

4. `super(name)` 通常写在子类构造的（  ）  
   A. 任意位置都行  
   B. 第一行（在赋自己字段之前）  
   C. 最后一行  
   D. main 里
