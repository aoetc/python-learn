**选择速记**

| 题 | 答 | 一句记法 |
|----|----|----------|
| 1 | B | 基本类在 `java.lang`（String、System），自动导入 |
| 2 | A | `paint(Graphics g)`，参数类型是 Graphics |
| 3 | C | 常量全大写；类/接口首字母大写；变量方法首字母小写 |
| 4 | D | 一个 `.java` 里最多一个 `public` 类 |

| 6/7 | D | 入口必须是 `public static void main(String[] args)` |
| 8 | C | javadoc 用 `/** ... */` |
| 9 | B | 编译后是 `.class` 字节码 |

**判断速记**

| 题 | 答 | 一句记法 |
|----|----|----------|
| 10 | 错 | main 要带 `String[] args`，不是可有可无 |
| 11 | 错 | Java **区分**大小写 |
| 12 | 对 | 安全、可移植、平台无关 |
| 13 | 对 | 先编译成字节码，再由 JVM 解释/执行 |
| 14 | 对 | `println` 换行，`print` 不换行 |
| 15 | 对 | `new Scanner(System.in)` 读键盘 |

| 17 | 错 | 运行写 `java HelloWorld`，**不要**加 `.class` |
| 18 | 对 | 字节码要靠 JVM 才能在机器上执行 |
