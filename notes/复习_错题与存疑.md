## bool 是什么

`bool` = 布尔类型，只有两个值：**`True`** 和 **`False`**（首字母必须大写）。

用来表示「是 / 否」，常见出现在 `if` 的条件里：

```python
is_student = True
if is_student:
    print("是学生")
```

`==`、`>=`、`in` 的结果也是 bool：`score >= 60` 要么 `True` 要么 `False`。

## 口述第三问：`[]` 什么时候造 list，什么时候取值

- **单独出现、用来赋值造容器** → 造 list：`scores = [90, 85]`
- **写在已经有的变量后面** → 取值（查），不是造 list：
  - `scores[0]`：list / tuple 按下标查
  - `grade["李宏"]`：dict 按键查

## 第 9 天（函数参数，存疑）

| 题 | 你当时 | 答案 | 记住 |
|----|--------|------|------|
| 小结「命名关键字」 | 问为什么必须 `city="杭"` | `*` 后面的不能按位置递 | `*` 是挡板：后面只能 `名字=值` |

`def f(a, *, city)` 里，`*` 不是参数，是挡板。挡板前的 `a` 可以按顺序递；挡板后的 `city` 必须写成 `city=...`，写成 `f(1, "杭")` 会报错。

`avg` 通解骨架：

```python
def avg(x, *args):
    total = x
    for n in args:
        total = total + n
    return total / (1 + len(args))
```

## 两数之和（写法坑）

- `for x in nums` 不要写成 `nums()`（list 不是函数）
- 变量名用 `nums`，不要写成 `num[i]`
- `if` 后面要 `:`，成立时的 `print` / `return` 必须缩进在 `if` 里面
- 要下标：`for i in range(len(nums))`，内层 `range(i+1, n)`
- `return [i, j]` 放在 `if` 里；本地练习用 `print`，不要把 `return` 写在循环外面

通解骨架：

```python
n = len(nums)
for i in range(n):
    for j in range(i + 1, n):
        if nums[i] + nums[j] == target:
            return [i, j]
```
