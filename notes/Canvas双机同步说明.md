# Canvas 规划页（双机同步）

可勾选的三年规划页源文件在仓库：

`canvases/hangzhou-agent-roadmap.canvas.tsx`

勾选进度备份（可选）：`canvases/hangzhou-agent-roadmap.canvas.data.json`

## Windows（已在用）

Cursor 会从本机 projects 目录加载 Canvas。仓库里这份是**备份 + 给 Mac 用的源**。

## Mac 上第一次启用

1. Pull 最新 `python-learn`
2. 用 Cursor 打开 `~/Developer/python-learn`（或你的实际路径）
3. 对新对话说：「把仓库里 canvases/hangzhou-agent-roadmap.canvas.tsx 安装成右侧 Canvas」
   - 或让 AI 复制到当前工作区的 `~/.cursor/projects/<本仓库>/canvases/` 下
4. 打开该 `.canvas.tsx` 文件，右侧应出现「小白今日」等页签

文字版 roadmap 仍在：`notes/roadmap_杭州Agent_2026市场校准版.md`
