## 单格战士 · 日常作战卡（贴桌上那张）

```
今天有没有 P1 硬课/作业？
  有 → P1 先完成，但必须留下 25～40 分钟 P0（最小剂量）
  无 → P0 用满 1～2 小时（可拆两段）
P0 结束 → 再玩手机 / P2 金融
整周 P0=0 → 违规；下周只修习惯，不加新目标
```

**进度反馈（喂你的 B 驱动）每月看一眼：**

1. 仓库/题号又多了什么？  
2. 简历上多了一句真的吗？  
3. 离「能投/在投/有着落」哪一格？
