### 函数是什么

函数 = **把一段常用操作打成包，起个名字，需要时喊一声**。

- **调用**：用别人（或自己）做好的包，例如 `print(x)`、`len(nums)`、`int("12")`
- **定义**：自己做包，用 `def 名字(...):`，里面写步骤，用 `return` 交结果

```python
def is_pass(score):
    return score >= 60

print(is_pass(90))   # True
```

### 调用时记住的几个

| 函数 | 作用 |
|------|------|
| `print` / `input` | 打印 / 读入（`input` 得到的是 **str**） |
| `len` / `type` | 长度 / 看类型 |
| `int` / `float` / `str` | 类型转换：已经是数字就别加引号，如 `int(12.34)`；是文字才 `int("12")` |
| `isinstance(x, int)` | 问「是不是这种类型」，第一遍了解即可 |

### 参数：怎么把东西递进去

| 种类 | 长相 | 人话 |
|------|------|------|
| 位置参数 | `def f(a, b)` → `f(1, 2)` | 按顺序递 |
| 默认参数 | `def f(a, b=0)` | 不传就用默认；**默认值别写 `[]`**，用 `None` 再在里面建 list |
| 可变参数 | `def f(*args)` → `f(1,2,3)` | 个数随便；里面 `args` 是 **tuple**；可以空 `f()` |
| 关键字参数 | `def f(a, **kw)` → `f(1, city="杭")` | 多出来的 `名=值` 收成 **dict**；一个没有就是 `{}` |
| 命名关键字 | `def f(a, *, city)` → 必须 `f(1, city="杭")` | `*` 后面的必须写名字；第一遍看懂即可 |

已有 list 要塞进可变参数：`f(*nums)`，等于把 list 拆开传。

`*args` 只是习惯名字，和 `*numbers` 同类；**可以为空**。

### 和「list 可变」别混

- `calc([1,2,3])`：普通参数，你要自己打成一包再传  
- `calc(1,2,3)`：可变参数 `*numbers`，直接传多个数  
- 「可变参数」= **个数可变**，不是说 list 可变

## 一、选择题（每题单选）

**1.** 下面哪个是「定义」函数？B

- A. `print(len([1, 2]))`
- B. `def add(a, b): return a + b`
- C. `x = int("3")`
- D. `input("名字：")`

**2.** `input("分数：")` 得到的类型通常是？ C

- A. `int`
- B. `float`
- C. `str`
- D. `bool`

**3.** `int(12.34)` 的结果是？B

- A. `12.34`
- B. `12`
- C. `"12"`
- D. 报错（因为没加引号）

**4.** 关于默认参数，正确的是？B

- A. 默认值写成 `L=[]` 最安全
- B. 默认值不要用 list，常用 `None`，在函数里再 `L = []`
- C. 默认参数不能使用
- D. 默认参数和 `*args` 是同一个东西

**5.** `def calc(*numbers):` 调用时，正确的是？B

- A. 只能 `calc([1, 2, 3])`
- B. 可以 `calc(1, 2, 3)`，也可以 `calc()`
- C. 必须正好传 2 个数
- D. `*` 表示这个函数不能有参数

**6.** 已有 `nums = [1, 2, 3]`，要传给 `def calc(*numbers):`，推荐写法是？B

- A. `calc(nums)`
- B. `calc(*nums)`
- C. `calc(**nums)`
- D. `calc(nums[])`

**7.** `def person(name, age, **kw):` 调用 `person("Bob", 35)` 时，`kw` 是？C

- A. `None`
- B. `[]`
- C. `{}`
- D. 报错

**8.** `person("Bob", 35, city="Beijing")` 时，`kw` 大约是？C

- A. `"Beijing"`
- B. `("city", "Beijing")`
- C. `{"city": "Beijing"}`
- D. `city=Beijing`（不是 dict）

**9.** 命名关键字参数 `def f(*, city):` 的正确调用是？B

- A. `f("杭州")`
- B. `f(city="杭州")`
- C. `f(["杭州"])`
- D. 只能 `f()`

**10.** 把乘积改成「一个或多个数」时，`mul(5)` 应该？B

- A. 报错，因为乘积至少要两个数
- B. 返回 `5`（一个数的乘积就是它自己）
- C. 返回 `0`
- D. 返回 `None`

## 二、判断题（对 / 错）

**1.** `*args` 和 `*numbers` 是同一类写法，只是名字不同。对

**2.** `*args` 不可以为空，至少要传一个参数。错

**3.** `return` 会把结果交出去，函数到这里通常就结束了。对

**4.** `int("12.34")` 和 `int(12.34)` 效果完全一样。错

**5.** 关键字参数 `**kw` 在函数内部是 dict；没传额外参数时是空 dict `{}`。对

**6.** 「可变参数」的意思是：list 是可变的，所以函数也可变。错

**7.** 函数体必须缩进。对

**8.** 递归是函数自己调用自己；按计划第一遍可以先不做。对
