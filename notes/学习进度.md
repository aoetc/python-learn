## 薄弱点速览（复习优先看错题本全文）

完整表在 **`notes/复习_错题与存疑.md`**。这里只列「反复要小心」的：

1. `=` 赋值 vs `==` 判断  
2. `[]`：造 list vs 取值 / dict 按键  
3. `{}` 空 dict；空 set 用 `set()`  
4. 函数：默认参数可省略；`*` 拆包；空 `**kw` 是 `{}`；题目说返回就用 `return`  
5. 命名关键字：`*` 挡板后必须 `名字=值`  
6. `*args` 算平均：先累加，除法在循环外；必填参数空调用由 Python 报 TypeError  
7. 有效括号：篮子 + 后开先关（`basket[-1]`）  
8. 第 12 天：`input` 得到的是 str，`int("60")` → 整数 60，不是「字符就不能转」  
9. `open` 只是打开文件；进看出 `"r"`/`read`，出看出 `"w"`/`"a"`/`write`  
10. 中文用 `encoding="utf-8"`；`write` 要 str；`readlines()` 要括号，结果先存进变量再 for

第 11 天（模块/venv）以实操为主，无单独错题节则算过关。
