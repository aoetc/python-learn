### 三个必须说清的修正

1. **Python 不能再说"几乎默认"**。上一版 77% 是错的：多条 JD 只写"熟练使用一门语言""Python/Java 任一"，恒生和课智的 JD 里甚至没点语言名。**写死 Python 的恰恰是杭州创业公司和实习岗**（烛龙、Plantcore、J10441、实习僧条）。
   → 结论修正：Python 是**默认语言，但不是显性筛选条件**；你不会 Python 一定挂，会 Python 也不构成优势。
2. **AI Coding 是唯一显著上调的**（19% → 33%），并且从"加分"变成"硬性"：烛龙「熟练使用 Codex 或 ClaudeCode」、原创软件「opencode / open claw」、牛客条「Cursor/Claude Code 重度玩家」。这条比 MCP 更值得在阶段 B 里留证据。
3. **MCP 和 Skills 没有想象中普及**（各 19%），且**集中在应用工程岗**（MCP 4/4 全在应用工程）。上一版把它讲成"成建制出现"是过头的——准确说法是：**大厂 JD 已写入，创业公司跟进，整体渗透率约两成**。

### 应用工程岗的"四件套"（14 条子集）

RAG 79% → Tool 43% · 评测 43% → AI Coding 29% · MCP 29% → Skills 21%。
这四层的顺序就是面试官问你问题的顺序：**能不能检索对（RAG）→ 能不能调对工具（Tool）→ 能不能证明它变好（评测）→ 能不能和 AI 一起写（AI Coding）**。多 Agent（21%）和 LangChain（29%）在这之后。

## 六、结论（按五分类给判断）

1. **应用工程仍是最大的池子，且本科最友好**。恒生「智能体开发」、烛龙「Agent 工程师」（9-13K，本科）、课智「agent 开发实习」、杭师大那条（学历不限）——都在「本科 + 有作品」这一档。你阶段 B 做完，这一档是可投的。
2. **评测岗是「低门槛进入、高上限」的隐藏入口**。曼孚明写「无需计算机背景、不限专业」，考的是实验设计与失败分析；华为云要的是评测体系/评测集/自动打分。**这正好是你阶段 B 里"10 条 BadCase"的自然延伸**——把 BadCase 升级成评测集 + 自动打分，就能投这一档。
3. **全栈岗要求最硬，但溢价明显**（PlantcoreAI：TS/React + 一种后端 + Docker + AI coding agent；箴羲 6-9K）。不建议现在补前端，除非你 2027 寒假有余量。
4. **售前岗真实存在且给钱不少（12.5-15K），但考察项不同**：方案 PPT、客户沟通、GPA 前 40%、学生组织经历。**不构成转金融分析的理由**，也不建议作为第一段实习的主叙事。
5. **数据工程是旁路**：每日互动语料治理、医疗数据基建。除非第一段实习迟迟没有应用向 offer，否则不碰。
6. **BOSS 上的高频词和官网是同一套，只是创业公司写得更"实"**：BOSS 岗把「Cursor 重度使用」「BadCase」「Skill」写成硬性；官网大厂把它写成"评测闭环/Agentic RL"。**同一能力，两种表述**——简历上用大厂词，面试里讲创业公司那种具体例子。
