### 题意（人话）

给你一个整数数组。若有**任意数字出现超过一次**，返回 `True`；每个数字都只出现一次，返回 `False`。

例子：

- `[1, 2, 3, 1]` → `True`（1 重复了）  
- `[1, 2, 3, 4]` → `False`

### 和两数之和的关系

两数之和用 dict 记「值 → 下标」。  
这题更简单：用 **set** 记「已经见过哪些数」——再遇到就说明重复。

最小思路（自己敲，别整段抄）：

```text
seen = set()
for 每个数字 x:
    如果 x 已经在 seen 里 → return True
    否则把 x 放进 seen
全部扫完 → return False
```

`x in seen` 很快；这就是今天说的「哈希」在入门题里的用法。
