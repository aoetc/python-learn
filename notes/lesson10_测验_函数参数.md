## 〇、先过一遍（做题前看，约 5 分钟）

参数 = **喊函数时递进去的东西**。就四种常用，别混：

```python
def f(a, b=0, *args, city, **kw):
    ...
```

人话从左到右：

1. **位置参数** `a`：按顺序递，`f(1, ...)` 里的 `1`
2. **默认参数** `b=0`：可以不递，不递就用 `0`。有默认的必须写在没默认的**后面**
3. **可变参数** `*args`：多出来的「按位置的数」收成 **tuple**，一个没有就是 `()`
4. **命名关键字** `city`（前面有单独的 `*` 或已经有 `*args`）：必须写 `city="杭"`
5. **关键字参数** `**kw`：再多出来的 `名=值` 收成 **dict**，没有就是 `{}`

最小例子：

```python
def greet(name, title="同学"):
    return f"你好，{title}{name}"

greet("李宏")           # 你好，同学李宏
greet("李宏", "老师")    # 你好，老师李宏
```

```python
def calc(*numbers):      # 个数随便
    s = 0
    for n in numbers:
        s = s + n
    return s

calc(1, 2, 3)            # 6
calc()                   # 0
nums = [1, 2, 3]
calc(*nums)              # 把 list 拆开，等于 calc(1,2,3)
```

`*` 挡板（你问过的）：

```python
def f(a, *, city):
    print(a, city)

f(1, city="杭")          # 对
# f(1, "杭")             # 错：city 不收位置
```

默认值**别写** `[]`：用 `None`，函数里再 `if L is None: L = []`。

## 一、选择题（每题单选）

**1.** 下面哪个定义是合法的？B,里面是不是有排序的，位置参数在前，默认参数在后？

- A. `def f(a=0, b):`
- B. `def f(a, b=0):`
- C. `def f(a=0, b=1, c):`
- D. 三个都合法

**2.** `def greet(name, title="同学"):` 调用 `greet("李宏")` 时，`title` 是？A-B

- A. 报错，因为少传了一个
- B. `"同学"`
- C. `None`
- D. `"李宏"`

**3.** `def calc(*numbers):` 里，函数内部的 `numbers` 通常是什么类型？C

- A. list
- B. dict
- C. tuple
- D. str

**4.** 已有 `nums = [10, 20]`，`def calc(*numbers):`，哪句能把 10 和 20 拆开传进去？B

- A. `calc(nums)`
- B. `calc(*nums)`
- C. `calc(**nums)`
- D. `calc(nums[])`

**5.** `def person(name, **kw):` 调用 `person("李宏", city="杭州")` 时，`kw` 是？C

- A. `"杭州"`
- B. `("city", "杭州")`
- C. `{"city": "杭州"}`
- D. `[]`

**6.** `def f(a, *, city):` 正确的调用是？B

- A. `f(1, "杭州")`
- B. `f(1, city="杭州")`
- C. `f(city="杭州")`（不传 a 也行）
- D. `f(1)`

**7.** 关于默认参数，正确的是？B

- A. 默认值写成 `L=[]` 最安全
- B. 默认值不要用 list，常用 `None`，在函数里再 `L = []`
- C. 默认参数和 `*args` 是同一个东西
- D. 有默认值的参数必须写在最前面

**8.** 「可变参数」指的是？B

- A. list 可变，所以函数也可变
- B. 调用时**个数可以变**（0 个、1 个、很多个都行，看你怎么定义）
- C. 函数名字可以变
- D. 必须传入一个 list

**9.** `def mul(x, *args):` 为什么第一个还要单独写 `x`？B

- A. 习惯而已，写成 `def mul(*args):` 且允许 `mul()` 也完全一样
- B. 这样 `mul()` 会报错（至少要一个数），`mul(5)` 时 `x` 是 5、`args` 是空 tuple
- C. `*args` 不能为空，所以必须再写一个 `x`
- D. `x` 必须是字符串

**10.** 参数从左到右，比较合理的顺序是？B

- A. 默认参数 → 位置参数 → `**kw` → `*args`
- B. 位置参数 → 默认参数 → `*args` → 命名关键字 → `**kw`
- C. `**kw` 必须写在最前面
- D. 顺序完全随便

## 二、判断题（对 / 错）

**1.** `*args` 和 `*numbers` 是同一类，只是名字不同。对

**2.** `def f(*, city):` 里的 `*` 是一个名叫星号的参数，调用时要传 `*=1`。错

**3.** `calc(*nums)` 的 `*` 表示：把 list/tuple **拆开**再传。错，应该是分别传入的吧？--一个意思的，正确

**4.** `person(**extra)` 的 `**` 表示：把 dict **拆成** `名=值` 再传。对

**5.** `def f(a=1, b):` 这种写法合法。错

**6.** 没传额外关键字时，`**kw` 在函数里是 `None`。对--错{}

**7.** 函数体必须缩进。对

**8.** 命名关键字必须写 `名字=值`，不能只按位置塞。对
