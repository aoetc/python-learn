## 二、高频需求（按出现频率）

### 硬技能（几乎条条都有）

| 关键词 | 出现情况 | 含义（人话） |
|--------|----------|--------------|
| **Python** | 极高 | 主语言；部分接受 Java 打底 |
| **Prompt / Prompt Engineering** | 极高 | 会写、会改提示词 |
| **Tool 调用 / Function Calling** | 极高 | Agent 会调外部工具 |
| **RAG** | 高 | 检索增强问答 |
| **Skills** | 高 | 技能模块 / SKILL 式能力封装 |
| **MCP** | 中高 | 工具/协议接入（加分或任职里出现） |
| **Agent / 智能体** | 极高 | 岗位主题 |
| **BadCase / 评测 / 测试集** | 高 | 效果评估、用例、可复用评测资产 |
| **Cursor / Claude Code / Codex / TRAE** | 极高（加分或硬性） | AI 编程工具**重度使用**，不是偶尔问问 |
| **Context / Memory / Subagent** | 中 | 上下文、记忆、子智能体——能谈理解即可到有实践 |
| **Harness Engineering** | 中（应用落地岗） | Agent 运行/编排/工程外壳相关说法 |
| **后端 / 接口 / FastAPI·Flask·Spring** | 中高 | 能独立写简单服务 |
| **LangChain / LlamaIndex / AutoGen** | 中（加分） | 框架用过优先 |
| **多 Agent / 编排** | 中（大厂/全栈岗） | 更后阶；不是每条实习都硬卡 |
| **Java / Spring** | 中（大厂 Agent 应用） | 双非冲大厂应用岗时的短板风险 |
| **Git / 工程习惯** | 中 | 可读可测代码 |

### 软要求 / 到岗

- 本科在读常见；部分写 26/27/28/29 届窗口  
- 每周 ≥3～5 天；实习 **≥3 个月**，部分希望 6 个月+  
- 要有**至少一个** LLM/Agent 小项目（课设/开源/个人均可）  
- 逻辑清晰、能拆需求、能扛「试错和无效功」

## 三、岗位「目标」在招什么人（抽象）

Boss 这批岗要的不是「会背大模型论文」，而是：

1. **能动手**：Python + 小项目/Demo  
2. **懂 Agent 零件**：Prompt、Tool、RAG、Skills，最好碰过 MCP / 评测  
3. **会用 AI 写代码**：Cursor/Claude Code 日常级  
4. **能闭环**：BadCase、评测集、文档、和业务/内部工具对齐  
5. **可选加深**：多 Agent 编排、Java 工程、全栈——多见于大厂或全栈岗

## 四、和「学生当前计划」的对齐（供挂载，不改主线）

学生现状：阶段 A 工程地板刚收口；阶段 B 将做最小 Agent 闭环（工具≥2、RAG、10 条评测、失败兜底、LangChain/Dify 一次、Skill 支线）。

| Boss 新强调点 | 建议挂载阶段 | 说明 |
|---------------|--------------|------|
| Cursor/Claude 重度使用 | **B（叙事）** | 已在用；结束时能讲案例 |
| Prompt / Tool / RAG / Skills / 评测 | **B 硬标准** | 与原计划一致，继续执行 |
| MCP | **B 了解 + 一次接入** | 已在 roadmap 附近，不必单独开坑 |
| BadCase / 评测集 | **B** | 原计划已有，截图再确认重要性 |
| Harness / 工作流拆解 | **B 末～D** | 先闭环再谈「业务工作流→AI 工作流」 |
| 多 Agent 编排 | **E** | 大厂岗有，但仍不宜挤掉 B |
| Java/Spring Agent 应用 | **课内 Java + E 前对齐** | 冲大厂应用岗再加码 |
| 数据基建 / SQL/ETL | **旁路** | 除非缺实习，不改 Agent 主线 |
| 同花顺售前/方案向 | **非主投** | 概念要懂，岗位性质偏沟通方案 |

## 六、一句话结论

> Boss 样本高度同构：**Python + Agent 零件（Prompt/Tool/RAG/Skills）+ 评测/BadCase + AI 编程工具重度使用**；多 Agent 与 Java 全栈是冲刺层；同花顺截图里混有售前向，筛选时要分开。学生原阶段 B 方向与市场同频，优先把 B 做实，再把截图里的「新词」挂到 B 叙事 / E 加深，而不是换赛道。
