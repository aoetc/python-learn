## 一、选项 A：`find`（推荐）

### 验收

1. 输入 `find`  
2. 再输入日期，例如 `2026-09-17`  
3. 只看到那天的行（你现在应能看到 `2026-09-17,100.0`）  
4. 若没有匹配：打印「没有这一天的记录」  
5. 无文件：友好提示，不闪退  

### 步骤

1. 写 `do_find()`（和 add/list 同级）  
2. `want = input("要查的日期：")`  
3. 读行，跳过表头（`first` / `lines[1:]` / `i==0` 都行）  
4. 每一行 `parts = line.split(",")`，若 `parts[0] == want`：`print(line)`，并记一下找到了  
5. 循环结束若一个都没找到：提示一句  
6. 菜单加上 `find`，README 补一句  

比较日期时注意：你文件里既有 `2026-09-17` 也有 `2026-9-15`（少了个 0）。**输入必须和文件里写的完全一样**才匹配。

## 二、选项 B：`delete`（备选）

### 验收

1. 先 `list` 看有几笔  
2. 输入 `delete` → 提示已删最后一笔  
3. 再 `list`：少了最后一笔，表头还在  
4. 若只有表头、没有数据：提示「没有可删的」  
5. 无文件：友好提示  

### 步骤思路

```text
读出 lines
若行数 <= 1（只有表头或空）：提示后 return
丢掉最后一行数据：例如 new_lines = lines[:-1]
   （注意最后一行若是空行，可能要先处理；有数据时 lines[:-1] 通常够用）
用 "w" 写回：把 new_lines 全部写进去
print 已删除
```
