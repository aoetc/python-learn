## 二、每条写什么（提示，不要整段抄）

### 1. 能 add

- 运行命令 → 输入 `add` → 输入日期和金额  
- 期望：提示已保存；`data/ledger.csv` 多一行  

### 2. 能 list

- 输入 `list`  
- 期望：能看到已有流水（有表头也正常）  

（可加一句：`summary` / `find` 也能用。）

### 3. 文件缺失怎么办

- 若没有 `data/ledger.csv`，输入 `list` / `summary` / `find`  
- 期望：打印友好提示（如「请先 add」），**不要**一整屏 Traceback  

（你代码里已有 `FileNotFoundError`，写进验收即可。）

### 4. 非数字金额怎么办

- `add` 时金额输入 `abc`  
- **先自己试一遍**，看现在会发生什么  
- 若会报错闪退：验收里写「当前会 ValueError；改进目标：提示后重试或回到菜单」  
- 若你愿意今天改：给 `float(input(...))` 加 `try/except ValueError`，再把验收写成「提示金额无效，不写进文件」  

两种都算完成第 24 天；诚实记录比假装已完美更重要。

### 5. 别人怎么安装运行

写给「刚 Pull 下来的人」，例如：

- 需要：已安装 Python 3；本仓库有 `.venv` 或自己会建  
- 步骤：打开 `python-learn` → 运行哪条命令 → 看到菜单  
- 提醒：不要进 `>>>` 交互环境里贴 shell 命令；不要提交真实账单
