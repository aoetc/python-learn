## 第2题思考题参考答法（用自己的话改写）

变量有**作用域**：在 `{ }` 代码块里声明的变量，出了这个块就不能再用。  
`k` 在内层块里声明，块外的 `println(k)` 会编译失败；`i` 是类的静态成员，在 `main` 里都能用。
