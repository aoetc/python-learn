# java_w05 题干

| 文件 | 做什么 |
|------|--------|
| `Ex01Extends.java` | `Person` 有 `name` 和 `sayHi()`；`Student extends Person` 增加 `score`；main 里 new Student，设 name/score，调用 `sayHi()` |
| `Ex02Super.java` | `Person(String name)`；`Student(String name, int score)` 里第一行写 `super(name)`，再设 score；show 打印姓名和成绩 |
| `Ex03OverrideIntro.java` | 父类 `show()` 只打姓名；子类 `@Override show()` 打姓名+成绩；对比调用 |

每个 `.java` 顶部有完整题干。
