对应阶段 **B**。  
测验：`notes/java_w04_测验_方法重载.md`

---

## 学什么

**重载**：同一个类里，方法**名字相同**，但**参数列表不同**（个数或类型不同）。  
编译器根据你传入的参数，决定调用哪一个。

和以后要学的「覆盖 override」不是一回事（覆盖是子类改写父类方法）。
