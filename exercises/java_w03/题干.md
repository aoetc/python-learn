# java_w03 题干一览

| 文件 | 题目 |
|------|------|
| `Ex01Student.java` | 写类 `Student`：字段 `name`、`score`；方法 `show()` 打印姓名和成绩；在 `main` 里 `new` 两个学生并调用 `show()` |
| `Ex02Constructor.java` | 给 `Student` 写构造方法 `Student(String name, int score)`；`main` 里用构造创建并 `show()` |
| `Ex03This.java` | 构造方法参数也叫 `name`/`score` 时，用 `this.name = name` 赋值；搞懂 `this` 是什么 |

每个 `.java` 顶部有完整题干注释。
